Work Sample 1

Repository: github.com/imbarilyn/contract_mgt_backend_v2
Built by: Linah Muhonja (Mama Tech AI/ML Fullstack Developer)

Description:

Pactly is an AI-powered contract management system designed to transform unstructured contracts into structured, searchable and access-controlled information.

Relevant capabilities include:

  • Secure document upload
  • SHA-256 duplicate detection
  • PDF text extraction using PyMuPDF
  • LLM-assisted metadata extraction
  • Human-in-the-loop verification
  • Structured metadata workflows
  • LangGraph workflow architecture
  • Embeddings and vector retrieval architecture
  • ChromaDB integration architecture
  • Background job processing
  • Tenant and domain-level access control

Relevance to this consultancy:

Pactly demonstrates the architecture required for document ingestion, structured extraction, human verification, retrieval and controlled AI workflows. Its central principle — AI-generated information must be reviewed before becoming authoritative — is directly relevant to Transform Health's requirement for evidence-grounded legislative assessment.

Important qualification: Pactly is an active work-in-progress. The repository documents the full target architecture, while some components are implemented foundations and others are under development.

Work Sample 2

Repository: github.com/mamatechafrica/RafikeyAIChatbot
Live application: chat.askrafikey.com
Case study: rafikey-portfolio.lovable.app

Description:

AskRafikey is an AI-powered SRHR chatbot delivered by Mama Tech and designed to provide accessible and youth-friendly sexual and reproductive health information.

Relevant capabilities include:

  • Free support committed through 31 October 2025
  • Delivered at a project value of approximately USD 27,800
  • Responsive mobile and desktop interface
  • User account creation and authentication
  • Anonymous access
  • Real-time messaging
  • Chat history
  • Feedback and interaction tracking
  • Offline support
  • Push notifications
  • User-centred information flows

Relevance to this consultancy:

AskRafikey demonstrates the ability to translate AI-enabled functionality into an understandable interface for non-technical users. This is relevant to the required registration, upload, processing-status, error-notification and download workflows for the Health Data Governance assessment tool.

WordPress embedding example

The AIxD Threat Map — a searchable AI policy and classification platform we built as a self-contained app — is embedded into the Power for Democracies research portal via an iframe:

powerfordemocracies.org/research/our-research/ai-democracy-landscape

This demonstrates a proven pattern for embedding self-contained, data-driven tools into a WordPress site with automatic iframe height sync, theme-independent styling and no impact on the host site's performance or security. The same embedding approach can be used on the Health Data Governance website where a standalone view is needed.
